# 已采用的决策

用户提供的 unified development V3 为本轮唯一开发基准；原计划和原核验保留，不删除、不追认未执行命令。

采用 V3 的 13 项已定决策。优先多模态建图，然后检索、证据约束计算、动态单 Agent 和工作台。正式问答固定审核快照，候选模式显著标识。关键知识审核不由 Codex 代签。

保留 Python 3.12.14、Semantica 0.7.0 和现有模型 API；不默认下载大型模型、不训练 QM、不部署 EGTR、不增加多 Agent 产品架构或复杂排程。无远端推送。

记录原组件运行、接口适配、领域重实现三种不同成果。结构关联和像素观测分别保存；不把价格、天数或配方归因于像素。

所有实现步骤命令由 `scripts/run_step.py` 保存原始退出码与输出。整体缺审核时不得报告正式验收 PASS。
