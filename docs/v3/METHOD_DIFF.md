# 方法实现与论文复用差异

| 方法环节 | 当前执行 | 命名与边界 |
|---|---|---|
| 原 mKG-RAG 独立函数 | 固定提交中的场景格式化、ROI 读取、实体与映射解析、图像属性融合函数体确已执行 | 原组件运行；不是原版全流程。relation parser 仅加载，未宣称执行 |
| 文本子图 | 通用 Wiki DOM / 表格提取，加有引用约束的模型候选 | 领域重实现；没有逐作物调度分支 |
| 视觉观测 | 实际像素解码；部分 Wiki 资源通过 ecnuplus 提取对象、区域及可见关系 | 模型调用与确定性像素统计分开计数 |
| 图文对齐 | 原图 / 区域、视觉观测、原文与候选 ID 经模型对齐；歧义、拒绝、冲突保留 | 接口适配与领域实现；不把图片说明升级为游戏规则依据 |
| Semantica | 真实 GraphBuilder、JSONExporter、ProvenanceManager；关系重实体化保留方向和多谓词 | 框架真实构图、持久化与来源；消歧与冲突规则由领域校验负责 |
| 问题感知重排 | BQ / D 共用 `chatecnu_question_pixel_rerank/v1`；输入问题、条件、用户区域像素、Wiki 区域和候选证据 | 可替换多模态适配器，不是训练 QM；无图片 / 无模型时明确词项降级 |
| Agent | ecnumax 原生工具调用；通用工具注册、证据补查与纯计算函数 | 动态单 Agent，无题号、问句或作物专用工作流 |
| 计算回答 | 按已执行规则的结构化输出生成结论；比较仅针对同数量、同条件的已计算方案 | 展示适配不选择业务工具链，不引入新价格、库存或公式 |

6 次实际图像联合重排调用已归档。同图不同问题可得到生长与加工的不同首列证据；该小样使用 Wiki 原图及显式实体输入，不是独立截图测试，不证明图像识别或图扩展的净收益。旧 72 次词项检索诊断原样保留。

随后4次更严格干预固定文本、条件、实体候选与候选证据集合，仅替换查询像素；BQ/D均随甘蓝/大蒜图片改变首列证据。这是接口的像素敏感性证据，仍无独立真实截图成绩。

模型辅助语义检查在实际旧回答上漏检过库存歧义，负例保存于 `answer_semantic_pilot.json`。因此计算类答案改为可信工具结果的确定性呈现；非计算回答的模型语义检查只作额外约束，不冒充人工审核或独立金标准。

换图 / 缺图 / 去上下文只操作隔离副本。有效上下文版本中，原图匹配、换图歧义、缺图无关联、去上下文歧义；初次空上下文实验也保留，明确其无法衡量去上下文影响。两次实验都没有修改正式或候选快照。

没有默认安装大型检测模型或训练原版 QM。未运行部分、固定提交、文件哈希和执行记录见 `UPSTREAM_MANIFEST.json`、`MKG_BUILD_REUSE.md`、`artifacts/v3/upstream/component_run.json`。本页不宣称完整复现 mKG-RAG 或效果已经优于基线。
